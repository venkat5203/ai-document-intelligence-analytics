# LinkedIn launch post (publish after the public app is deployed)

I’ve been working on a project that brings together two areas I enjoy: **data analytics and data quality**.

Introducing **Document Intelligence & Data Quality Analytics** — an end-to-end portfolio project built with Python, SQL, Streamlit, and an optional LLM-assisted extraction workflow.

What I built:

- Generated and analyzed 47,000 synthetic supplier-document records.
- Created a Python pipeline to extract and normalize fields from semi-structured text.
- Applied six validation checks to identify missing, malformed, and inconsistent values.
- Built an exception review queue and SQL queries for operational KPIs.
- Developed an interactive dashboard for trend analysis, quality monitoring, and record-level exploration.
- Added a versioned prompt template and optional live LLM extraction integration.

**A few results from the synthetic dataset:**
- 47,000 records processed
- 90.03% passed all six validation checks
- 4,684 records routed for review

All records and results are synthetic and are not employer or customer production data.

This project helped me bring together data extraction, validation, analytics, and AI-assisted workflows in one practical demonstration.
